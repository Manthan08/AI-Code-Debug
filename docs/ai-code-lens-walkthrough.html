AI Code Lens

A local bridge between Visual Studio debugging and AI coding agents.

Visual Studio extension Local MCP server C# / .NET MVP

The assistant can use real debugger context, not only pasted source code.

The problem

AI assistants usually debug with missing context.

  • They cannot see where Visual Studio is paused.
  • They cannot inspect live variables or the call stack.
  • They miss exceptions, build errors, and Output window details.

Why this exists

Debugging needs runtime evidence.

AI Code Lens gives the agent the same facts a developer checks during a real debugging session.

  • Current file and line
  • Selected stack frame
  • Live locals and exception details
  • Build errors and recent output

How it works

The bridge stays local.

A Visual Studio extension talks to a local MCP server. The AI agent calls MCP tools to request debugger context.

The MVP uses local stdio MCP and a named pipe to Visual Studio.

MCP configuration

Point the AI agent to the local server.

For development, the MCP server can run with dotnet run.

[mcp_servers.vs_debug_bridge]
command = "dotnet"
args = [
  "run",
  "--project",
  "PATH_TO_MCP_SERVER_CSPROJ"
]
startup_timeout_sec = 20
tool_timeout_sec = 60

For packaged use, point to the installed MCP server instead.

Safety boundary

Read first. Act only with approval.

Health check verifies the bridge.
Debug snapshot reads live debugger evidence.
Step, continue, and breakpoint tools require explicit approval.
